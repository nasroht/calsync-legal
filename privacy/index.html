Privacy Policy

Calendar Sync is a private, self-hosted personal automation tool.

  • Data Access: It accesses Google Calendar data solely to synchronize events between the owner's personal Apple iCloud and Google calendars.
  • Data Storage: Sync state and OAuth tokens are stored locally on the owner's machine only.
  • Data Sharing: No user data is collected, sold, transferred, or shared with any third parties.
